# Search Engine

This is a full-stack Search Engine application built using **Golang** for the backend and **React.js** for the frontend.  
The backend is responsible for processing and indexing data, while the frontend provides a clean user interface for querying and viewing search results.

---

## 🛠️ Tech Stack

- **Backend**: Golang
- **Frontend**: React.js

---

## 🚀 Getting Started

### Running the Project

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/search-engine.git
   cd search-engine
2. **Start the Backend**
   ```bash
   cd backend
   # Option 1: Run directly
   go run main.go

   # Option 2: Build and run
   go build -o app main.go
   ./app
3. **Start the Frontend**
   ```bash
   cd frontend
   npm install
   npm start
4. **Access the Application**
* Open your browser and go to: http://localhost:3000
5. **How to Use**

   In the UI, select a namespace.

   Enter a search query (example: integration-lab:otel-demo) into the input field.

   Click the Search button to see the results.
